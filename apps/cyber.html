// How Caesar Cipher Works
Each letter is replaced by a letter a fixed number of steps ahead in the alphabet.
Example with shift=3: A→D, B→E, C→F, Z→C
To decode, shift backwards by the same amount.

Find the Vulnerability

Code Review
// login.py — Code Review Required
1def login(username, password):
2 # Connect to the database
3 db = connect("school.db")
4 cursor = db.cursor()
5 query = "SELECT * FROM users WHERE name='" + username + "' AND pass='" + password + "'"
6 cursor.execute(query)
7 result = cursor.fetchone()
8 if result:
9 return "Login successful!"
10 return "Access denied."
// The Attack — SQL Injection
If a hacker types ' OR '1'='1 as the username, the query becomes:
SELECT * FROM users WHERE name='' OR '1'='1' AND pass='...'
Since '1'='1' is always true, they get in without knowing any password!
